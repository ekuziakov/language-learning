# Карточки для изучения языков в Mochi с помощью ИИ

[English](README.md) · Русский

Создавайте небольшие уроки под свои цели с помощью ИИ-ассистента для работы
с кодом и повторяйте их офлайн в [Mochi](https://mochi.cards/). Вы выбираете
родной и изучаемый языки, рассказываете о своих задачах и просите создать набор.
Ассистент сохраняет исходники локально и запускает сборку, а вы импортируете
готовые файлы в Mochi.

Это **не готовый курс и не отдельный ИИ-сервис**, а набор скриптов, инструкций
для ассистента и небольшой пример формата. Ваш профиль, план занятий,
карточки и созданные медиа хранятся локально и исключены из Git.

## Что получается

Каждый набор автоматически собирается в две колоды:

| Колода | До открытия ответа | После открытия ответа |
| --- | --- | --- |
| Обычная — production | Подсказка на родном языке и иллюстрация | Текст на изучаемом языке, аудио, разбор слов и объяснение |
| На слух — listening | Аудио и нейтральное задание, без текста реплики и картинки-подсказки | Текст реплики, перевод, иллюстрация и объяснение |

- Короткие фразы и слова под ваши цели и уровень.
- Разбор каждого слова и объяснение построения предложения.
- Примеры употребления с переводом для отдельных слов.
- Картинки для слов и иллюстрации ситуаций для фраз.
- Локальная синтетическая озвучка; аудио и изображения включены в `.mochi`.
- Офлайн-повторение после импорта, без аккаунта и подписки Mochi Pro.
- Повторное использование аудиофайлов и стабильные ID карточек.

Объяснения и картинки подготавливает ассистент; скрипт упаковывает материалы.
Сам скрипт не обращается к языковой модели, не переводит и не рисует.
Если точность особенно важна, проверяйте язык и произношение по надёжным источникам.

## Требования

- Приложение **Mochi** на компьютере или телефоне для импорта и повторения.
- **macOS** для генерации речи встроенным в проект способом.
- **Python 3.10+** и **ffmpeg**, доступные из командной строки.
  Сторонние Python-пакеты не нужны.
- Установленный голос macOS для изучаемого языка. Список: `say -v '?'`.
- ИИ-ассистент для работы с кодом, который умеет читать файлы проекта
  и выполнять локальные команды, либо ручное редактирование JSON.
  Если ассистент не загружает `AGENTS.md` автоматически, попросите его прочитать файл.

Для озвучки используется команда macOS `say`, а не встроенный TTS Mochi.
Скачивание дополнительных голосов, моделей и использование платных облачных
сервисов — только с вашего согласия. У ИИ-ассистента могут быть свои тарифы;
он также может отправлять запросы своему провайдеру. «Локально» здесь относится
к хранению учебных материалов и генерации речи, а не обязательно к самому ИИ.

## Начало работы

### 1. Скачайте и откройте проект

```sh
git clone https://github.com/ekuziakov/language-learning.git
cd language-learning
```

Откройте эту папку в своём ИИ-ассистенте.

### 2. Настройте обучение под себя

Вставьте следующий промпт, заменив значения в скобках. Можно также попросить
ассистента задать вам эти вопросы по очереди.

> Прочитай AGENTS.md и помоги настроить проект. Мой родной язык — [язык],
> хочу изучать [язык / региональный вариант]. Общайся со мной и объясняй
> карточки на [язык]. Мой уровень — [уровень], цель — [цель],
> срок — [дата], на занятия могу выделять [минут] в день.
> Уточни недостающие сведения и помоги выбрать установленный голос macOS.
> Сохрани профиль в .local/settings.json, личные инструкции —
> в .local/INSTRUCTIONS.md, согласованный план — в .local/PLAN.md.
> Не добавляй мои личные данные и учебные материалы в отслеживаемые Git файлы.
> Пока не создавай большой курс.

Ассистент может запустить интерактивную настройку, или вы можете сделать это сами:

```sh
python3 scripts/setup.py
```

Чтобы предварительно посмотреть доступные голоса:

```sh
say -v '?'
```

Для настройки без интерактивных вопросов передайте параметры
`--native-language`, `--target-language`, `--voice` и `--locale`.
Необязательные `--conversation-language` и `--explanation-language` по умолчанию
совпадают с родным языком; `--rate` по умолчанию равен 145.

Языки, голос и скорость речи сохраняются в `.local/settings.json`.
Поле `locale` описывает акцент голоса, но не выбирает голос само по себе.
Для изменения настроек отредактируйте профиль: скрипт не перезаписывает
существующий файл. В поле `listening_prompt` можно перевести задание для
карточек на слух на удобный вам язык.

### 3. Попросите создать небольшой набор

> Прочитай мой локальный профиль, инструкции и план. Создай небольшой набор
> из [число] учебных единиц на тему [тема]. Сохрани исходник
> в cards/[имя-набора].json. Включи полезные фразы, которые я буду говорить,
> и реплики, которые могу услышать в ответ. Добавь разбор слов, примеры
> для отдельных слов и подходящие локальные изображения. Собери обычную
> колоду и listening, проверь файлы и укажи, что импортировать.
> При изменении существующего набора сохраняй ID.

Например, 5 учебных единиц превращаются в 5 обычных карточек и 5 карточек
на слух. Отдельно просить listening не нужно: он собирается каждый раз.

### 4. Импортируйте оба файла в Mochi

Из исходника `cards/lesson-01.json` получатся:

```text
exports/lesson-01.mochi
exports/lesson-01-listening.mochi
```

Выберите импорт в Mochi и загрузите каждый файл. Аудио и изображения уже внутри —
прикреплять их отдельно не нужно. Проверьте по одной карточке каждого направления,
воспроизведите аудио, а затем проверьте его работу без интернета.

**Обновление колоды:** сначала экспортируйте резервную копию из Mochi.
Стабильные ID сами по себе не гарантируют, что повторный импорт обновит карточки
без дублей и сохранит расписание повторений. Сначала проверьте поведение
на отдельной пробной колоде. Не удаляйте изучаемую колоду ради загрузки новой версии.

## Как заниматься

Сначала проходите назначенные повторения, затем добавляйте несколько новых
карточек, если нагрузка позволяет. В обычных карточках произносите ответ вслух
до его открытия. В карточках на слух старайтесь понять смысл, а не перевести
дословно. Применяйте те же слова и фразы в коротких диалогах с ассистентом.
Одна только текстовая переписка не тренирует понимание речи на слух.

## Сборка и тесты вручную

После создания локального профиля можно собрать тестовый пример из одного слова:

```sh
python3 scripts/build.py examples/sample.json
```

Получатся `exports/sample.mochi` и `exports/sample-listening.mochi`.
В примере подсказка на английском, а ответ — на испанском: для проверки выберите
совместимый голос в профиле. Это только пример формата, а не заданная для вас
языковая пара.

Для собственного набора:

```sh
python3 scripts/build.py cards/my-set.json
```

Структурные тесты не требуют голоса, аккаунта, личных данных или ffmpeg:

```sh
python3 scripts/test_build.py
```

## Файлы и приватность

| Путь | Назначение | В Git? |
| --- | --- | --- |
| `README.md`, `README.ru.md` | Руководство пользователя на английском и русском | Да |
| `AGENTS.md` | Универсальные инструкции для ИИ-ассистента | Да |
| `scripts/` | Настройка, сборка и тесты | Да |
| `examples/` | Небольшой пример формата | Да |
| `.local/` | Профиль, личные инструкции и план | Нет |
| `cards/` | Редактируемые исходники ваших наборов | Нет |
| `images/`, `audio/` | Ваши иллюстрации и озвучка | Нет |
| `exports/` | Файлы для импорта в Mochi | Нет |

Правила игнорирования Git — не шифрование и не резервная копия.
Самостоятельно сохраняйте копии личных материалов. Не публикуйте API-ключи
и не добавляйте игнорируемые файлы принудительно. Ранние версии проекта содержали
учебные данные автора: правила игнорирования не удаляют уже опубликованное
из истории Git.

## Ограничения

- Включённый способ генерации речи работает только на macOS.
  Для других систем нужен другой способ озвучивания.
- Доступные языки и акценты зависят от установленных голосов macOS.
- Озвучка синтетическая, а не запись носителя.
- Файлы `.mochi` используют документированный формат архивов EDN v2
  и встроенные ссылки на медиа. Структурные тесты не проверяют отображение,
  воспроизведение и повторный импорт внутри Mochi. В частности, отображение
  SVG нужно проверить в вашей версии приложения.
- Автоматического управления приложением, подключения аккаунта и облачной
  синхронизации нет.

Поля карточек, правила ID и инструкции по подготовке материалов —
в `AGENTS.md` и `examples/sample.json`.

Документация Mochi: [импорт](https://mochi.cards/docs/import-and-export/importing/)
и [формат архивов](https://mochi.cards/docs/import-and-export/mochi-format-reference/).
