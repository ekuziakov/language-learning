# Project instructions

- Общаться с пользователем по-русски. Цель — практический испанский для поездки
  по Южной Америке; преимущество латиноамериканским вариантам.
- Исходники карточек хранятся в `cards/*.json`, аудио в `audio/`, сборки в `exports/`.
- Согласованы два небольших учебных набора и дополнение по оплате.
  План — в `PLAN.md`. Не создавать большие новые наборы и темы без согласования.
- На текущем этапе озвучивание локальное: macOS Paulina (es-MX). Не подключать
  платные API, скачивание моделей или встроенный TTS Mochi без согласования.
- Не выдавать синтетическую речь за запись носителя. Мексиканский голос не
  описывать как чилийский.
- Карточка должна проверять одну небольшую единицу. Для каждой единицы нужны
  RU → ES и аудио ES → понимание смысла. Регионализмы явно помечать,
  избегать русской транскрипции.
- На обороте добавлять разбор каждого слова (устойчивые выражения объяснять
  целиком с пояснением компонентов) и объяснение построения фразы: формы
  глаголов, порядок слов, опущенные местоимения. Уровень — для начинающего.
- В карточках отдельных слов на обороте также давать 1–2 коротких примера
  употребления на испанском с переводом на русский, преимущественно из
  бытовых ситуаций поездки. Примеры — пояснение, не дополнительное задание.
- Для всех карточек создавать обратную пару (`include_reverse: true` в колоде).
  Исходная запись хранится один раз; сборщик создаёт пару со стабильным ID:
  суффикс `Audio` для RU → ES, `Recall` для исходной audio-ru.
  Также добавлять полезные реплики собеседника. Для карточек на слух:
  `direction: "audio-ru"`. На лице только аудио и нейтральное задание,
  без текста реплики, перевода или картинки-подсказки; на обороте испанский
  текст, русский смысл и разбор. Не требовать дословного перевода.
- Картинка нужна для каждой единицы: на лице RU → ES вместе с русской
  подсказкой, на обороте audio-ru. Для абстрактных фраз — иллюстрация ситуации.
  Локальные SVG в `images/` включаются в архив; отображение проверять в Mochi.
- Сохранять стабильные ID карточек. Не обещать обновление колоды без дублей,
  пока поведение повторного импорта не проверено.
- Не удалять старые аудиофайлы и пользовательские материалы автоматически.
- Проверка ZIP и аудио не равна успешному импорту в Mochi: это отдельный тест.
